Use "oracle" agent with forked context to provide a second opinion on the current plan.

Ask oracle to:
1. Challenge assumptions in the plan
2. Identify risks, edge cases, and failure modes
3. Suggest safer or simpler alternatives
4. Flag any unapproved scope/product/architecture decisions

Oracle is review-only. Do not edit files.

If oracle raises concerns, pause and discuss before proceeding.
